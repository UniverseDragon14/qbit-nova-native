## Scope boundary

This proves that the public repository contains the identical GHZ3 **source file** used by the recorded run and that the recorded development build produced matching source/QBC histograms.

It does **not** prove that the older public `main` compiler binary is identical to the development-branch compiler, because later Stage6/Stage7/V10 implementation files are not present on public `main`. Reproduce the build on this exact branch before assigning the same QBC hash to it.

It also does not prove physical quantum hardware, quantum speedup or hardware quantum randomness.
